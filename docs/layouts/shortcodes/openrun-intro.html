OpenRun is an open source self-hosted GitOps platform for deploying web apps and internal tools declaratively. Deploy on a single node with Docker/Podman, or deploy apps onto a Kubernetes cluster. OpenRun adds the authentication, authorization and auditing features required by teams. Code-first apps get the platform capabilities usually found in enterprise low-code tools like Retool.
